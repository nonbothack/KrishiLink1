# Institutional UAT plan

Automated tests are supporting evidence and are not UAT sign-off. Execute these scenarios with realistic, non-production data and record preconditions, steps, expected result, evidence, pass/fail and issue reference.

| Persona | Scenarios |
|---|---|
| Farmer | OTP, reported price lookup, Sell, offer, Trade Room, support, offline draft/retry, simple mode and language |
| Buyer | requirement, supply discovery, offer/counter, trade and records |
| FPO | member roster/import, intake/receipt/correction, pool, publish, trace and projected allocation |
| Admin/operator | verification, support, fraud signal, outbox, feature flag, provider health and incident |
| Support/reviewer | least-privilege lookup, safe notes, escalation and privacy request queue |

Record viewport, browser, language, network state, authorization identity and evidence location for each scenario.
