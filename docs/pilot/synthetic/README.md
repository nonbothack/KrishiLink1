# Packet 16S synthetic evidence

This directory contains synthetic usability rehearsal evidence only. It is not farmer, buyer, FPO, operations, adoption, satisfaction, income, fill-rate, throughput, or real-user research evidence.

The rehearsal used a local OpenUser browser run and an isolated MiroFish simulation. Third-party repositories, personas, videos, screenshots, and full simulation outputs remain outside this repository. Only redacted summaries and non-secret identifiers are retained here.

The real Packet 16 result remains `BLOCKED / INSUFFICIENT` because no paid, consented participants have completed sessions. Synthetic output must not be fed to `scripts/analyze_pilot_sessions.py` or used to change that status.
