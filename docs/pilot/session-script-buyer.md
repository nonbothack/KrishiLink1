# Buyer moderated-session script

Use an isolated buyer account and synthetic listings. No real procurement commitment is made.

1. Explain what “business verified” means and what it does not mean.
2. Create or edit a requirement with canonical crop, quantity, unit, geography and timing. Explain which fields are authoritative.
3. Discover an FPO and farmer lot. Identify the seller display identity and lot facts. Confirm that member names, phones, receipts and allocations are not exposed.
4. Submit a test offer and explain price, quantity, expiry, terms and gross. Verify that a retry does not duplicate the offer.
5. Review a counter/accept flow and the resulting canonical Trade Room. State which terms are immutable and which payment evidence is unavailable.
6. Find support and notifications. Explain which object each deep link opens and what another buyer must not see.

Debrief on comprehension, missing information, privacy expectations and procurement risks. Record any desire to see data that the product intentionally withholds as a product question, not permission to expose it.
