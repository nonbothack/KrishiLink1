# Farmer moderated-session script

Use a staging account and synthetic test records. Read tasks verbatim, do not coach unless the observation form records the assistance.

## Opening and five-second test

Show the authenticated home screen for five seconds, then hide it. Ask: “What would you do first, and what information did you notice?” Do not correct the answer until recorded.

## Tasks

1. Find the latest reported price for a crop you sell. State the amount, unit, market, report date and source. Say what the number does and does not promise.
2. Explain the location context shown. If it is missing or approximate, say what you would do next without granting GPS permission.
3. Start Sell and create a lot using only the information you know. Review crop, quantity, original unit, asking price, availability and indicative gross. Do not publish unless the moderator confirms the staging action.
4. Return to My Lots and explain the current status and available actions. Try a safe retry/double tap only in staging; verify that no duplicate is created.
5. Open a genuine test offer. Compare quantity, unit, price, gross, expiry and supplied terms. Explain what is unknown.
6. Accept or counter the offer in staging and describe what happens next in the Trade Room. Verify the agreed terms and timeline.
7. Find notifications and support. Explain what a notification deep link can open and where to raise a grievance.
8. On a mobile/intermittent-network segment, reload or temporarily disconnect during a draft. Verify that no consequential offer/trade action replays in the background and that retry is explicit.
9. On a shared-device account switch, verify the previous account’s draft and notifications are not visible. If simple mode or voice is enabled in the build, test it as an optional task and record whether it helps.

## Debrief

Ask which statement was hardest to understand, what they would distrust, whether the source/date was clear, and what would make them stop before publishing or accepting. Do not ask for a testimonial.
